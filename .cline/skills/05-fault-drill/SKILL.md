# 任务：帮我设计并"演练"3 次可控故障，生成排查记录

我需要在 K8s 集群里故意制造故障、排查、恢复，并把过程写成文档。请给我 3 个由易到难的故障剧本，每个剧本按以下格式输出：

## 故障剧本格式
- 故障名称与现象（我会看到什么，如 Pod 状态、页面报错）
- 制造方法（具体命令，如 kubectl 删 PVC、改错镜像 tag）
- 排查步骤（每一步 kubectl 命令 + 预期输出长什么样）
- 根因与修复
- 论文/面试话术：用第一人称写一段 150 字的"我当时是怎么发现和解决的"

## 三个剧本指定为
1. ImagePullBackOff（镜像 tag 写错）
2. CrashLoopBackOff（配置错误导致启动即崩溃，比如改错数据库连接）
3. Service 不通（Service 的 selector 和 Pod label 不匹配，探针全通过但 Ingress 访问 503）

这些排查记录将作为论文附录《故障处理手册》和面试故事库，请写得像真实操作笔记。
